# Rentaly para Windows

Instalador del programa de escritorio de **Rentaly**, el sistema de administración de rentas de
Representaciones Vega. Uso exclusivo de la oficina.

**Descargar:** en [Releases](../../releases/latest) › `Rentaly-Instalador.exe`.

- El programa abre el sistema en su propia ventana; para entrar se necesita usuario, contraseña
  y código de verificación.
- Se actualiza solo: al abrirlo revisa si hay una versión nueva, la descarga y se instala al cerrarlo.
- Este repositorio solo contiene el instalador. El sistema y los datos son privados.
